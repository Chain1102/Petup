# PetUp Mobile (Android / iOS)

แอปเดิมห่อด้วย Capacitor เพิ่มการปลุกและเตือนแบบเนทีฟ (แจ้งเตือนตามเวลาของระบบมือถือ) ทำงานได้แม้ปิดแอป
แตะที่แจ้งเตือนปลุก → แอปเปิดหน้า Quest (เขย่า/โจทย์เลข) → ได้สตรีคและรางวัล

## สิ่งที่ต้องมี
- Node.js 20 ขึ้นไป
- Android: Android Studio  |  iOS: Mac + Xcode (สร้าง iOS บน Windows ไม่ได้)

## ขั้นตอน
```
npm install
npm run setup:android     # สร้างโปรเจกต์ Android + ไอคอน + สิทธิ์ปลุก
npm run android           # เปิด Android Studio แล้วกด Run (ต่อมือถือหรือใช้ emulator)
```
iOS (บน Mac):
```
npm run setup:ios
npm run ios               # เปิด Xcode → เลือก Team ใน Signing → Run
```
แก้ไขแอป: แก้ `www/index.html` แล้วพิมพ์ `npm run sync`
สร้างไฟล์ติดตั้ง Android: Android Studio → Build → Build APK(s) (หรือ Generate Signed Bundle สำหรับ Google Play)

## ครั้งแรกที่เปิดบนมือถือ
- กดอนุญาตการแจ้งเตือน
- Android 12+: จะพาไปหน้า "ปลุกและเตือน (Alarms & reminders)" ให้เปิดสิทธิ์
- เครื่อง Xiaomi/Samsung/OPPO: ตั้งแอปเป็น "ไม่จำกัดแบตเตอรี่" และอนุญาตเริ่มอัตโนมัติ ไม่งั้นระบบอาจฆ่าการแจ้งเตือน

## ได้ไฟล์ APK โดยไม่ต้องติดตั้ง Android Studio (ใช้ GitHub ฟรี)
โปรเจกต์นี้มีตัวสร้าง APK อัตโนมัติ (`.github/workflows/build-apk.yml`) ทำตามนี้:
1. สมัคร https://github.com (ฟรี) แล้วกด **New repository** ตั้งชื่ออะไรก็ได้ เลือก Public หรือ Private
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (Add file → Upload files แล้วลากทั้งโฟลเดอร์)
   - ถ้าโฟลเดอร์ `.github` ไม่ขึ้น: กด Add file → Create new file ตั้งชื่อ `.github/workflows/build-apk.yml` แล้ววางเนื้อหาจากไฟล์นั้น
3. **ลิงก์ดาวน์โหลดถาวร:** ไปที่ Releases → Create a new release → ตั้ง tag เป็น `v1.0.0` → Publish
   รอประมาณ 5–10 นาที (ดูความคืบหน้าที่แท็บ Actions) ไฟล์ `PetUp.apk` จะขึ้นในหน้า Release ให้กดโหลด/แชร์ลิงก์ได้
   - หรือไปแท็บ Actions → Build Android APK → Run workflow แล้วโหลดจาก Artifacts (ต้องล็อกอิน GitHub)
4. บนมือถือ: เปิดลิงก์ โหลด `PetUp.apk` แล้วติดตั้ง (ต้องอนุญาต "ติดตั้งจากแหล่งที่ไม่รู้จัก" และ Play Protect อาจเตือนเพราะเป็นแอปที่ไม่ได้มาจาก Play Store)
ไฟล์นี้เป็น debug APK ใช้ทดสอบและแชร์ให้คนอื่นลองได้ ถ้าจะขึ้น Google Play ต้องสร้าง release ที่เซ็นด้วย keystore ของคุณเอง

## ปลุกได้โดยไม่ต้องเปิดแอปหรือเปิดจอ (Android)
`npm run setup:android` ติดตั้งโมดูลปลุกเนทีฟให้อัตโนมัติ (โฟลเดอร์ `native/android`, สคริปต์ `scripts/patch-android.js` รันซ้ำได้ด้วย `npm run patch:android`)

ทำงานอย่างนี้:
1. ตั้งปลุกด้วย `AlarmManager.setAlarmClock()` ระบบปลุกเครื่องจากโหมดหลับ/Doze ตรงเวลา แอปไม่ต้องเปิดอยู่
2. ถึงเวลา → service เล่นเสียงปลุก (ช่องเสียงปลุก ดังแม้เครื่องตั้งโหมดเงียบ) + สั่นวน + เปิดหน้าจอ Quest ทับหน้าล็อกสกรีนเอง
3. ทำ Quest เสร็จ (หรือกดข้ามหลัง 90 วินาที) → แอปสั่งหยุดเสียง ถ้าแอปค้างเสียงจะหยุดเองหลัง 10 นาที และปัดแจ้งเตือนทิ้งก็หยุดเสียงได้
4. ตั้งปลุกของวันถัดไปเองหลังปลุกทุกครั้ง และหลังรีสตาร์ท/อัปเดตแอป/เปลี่ยนเวลา

**ครั้งแรกบนมือถือ:** เปิดแท็บ "ปลุก" จะมีการ์ดตรวจความพร้อม 4 อย่าง (ปลุกตรงเวลา, เปิดหน้าจออัตโนมัติ, แจ้งเตือน, ไม่จำกัดแบตเตอรี่) กด "ตั้งค่า" ตามข้อที่เป็น ❌ แล้วกด "ทดสอบปลุกใน 10 วินาที" ล็อกจอรอฟังได้เลย

## ข้อจำกัด (ตรงไปตรงมา)
- **โค้ด Java ชุดนี้ผมยังไม่ได้ build/ทดสอบบนมือถือจริง** (ทดสอบแล้วเฉพาะสคริปต์ติดตั้งและฝั่งเว็บกับปลั๊กอินจำลอง) ถ้า build ไม่ผ่าน ส่งข้อความ error มา แก้ได้ทันที
- เครื่อง Xiaomi/Samsung/OPPO/Vivo ต้องตั้ง "ไม่จำกัดแบตเตอรี่" และอนุญาตเริ่มอัตโนมัติ ไม่งั้นระบบอาจฆ่าแอป
- โหมดห้ามรบกวนแบบเข้มอาจกันเสียง ต้องเช็กที่เครื่อง
- เครื่องปิดอยู่จะไม่ปลุก
- ขึ้น Google Play: สิทธิ์ USE_EXACT_ALARM จำกัดสำหรับแอปปลุก/ปฏิทิน, USE_FULL_SCREEN_INTENT ต้องกรอกแบบประกาศ, foreground service (media playback) ต้องประกาศการใช้งานใน Play Console
- ใช้เสียงปลุกเริ่มต้นของเครื่อง ยังเลือกเสียงเองไม่ได้
- ปลุกซ้ำได้แบบรายวันเท่านั้น (ยังไม่มีเลือกวัน)
- iOS: ยังใช้แจ้งเตือนของระบบ (ปลุกเต็มรูปแบบต้องใช้ AlarmKit บน iOS 26+ ซึ่งเป็นขั้นถัดไป) และเก็บแจ้งเตือนที่ตั้งเวลาไว้ได้สูงสุด 64 รายการ
- ข้อมูลเก็บในเครื่อง ยังไม่มีบัญชี/ซิงก์ ใช้ส่งออก-นำเข้าที่แท็บสถิติ
